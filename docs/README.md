# Documentation

This directory is the durable reference layer for the product story and
implementation model.

Use these docs to learn:

- what the platform is
- how the layered architecture fits together
- how example projects are composed
- how the workspace UI is defined and composed
- how releases and milestones are tracked

Start with the path that matches your goal:

- [Architecture](./architecture/README.md): the layered model and decision records
- [Specs](./specs/README.md): intended behavior and acceptance criteria
- [Examples](./examples/README.md): the product model in practice
- [Releases](./releases/README.md): release notes and milestone summaries
- [Roadmap](../ROADMAP.md): implementation progress
- [Plans](../plans/README.md): active implementation handoffs

Use these maintenance rules:

- Update docs when intended behavior, structure, or user-facing behavior changes.
- Update plans when you are executing work against a stable spec.
